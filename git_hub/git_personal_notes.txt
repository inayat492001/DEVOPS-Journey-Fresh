Explain this command (git pull --ff-only origin main) is used to download the latest changes from GitHub's main branch and update your current local branch, but only if Git can do so without creating a merge commit.

Let's understand each part.
1. Breaking down the command
Part	Meaning
git	Git version control tool
pull	Fetch changes and integrate them into your current branch
--ff-only	Allow only a fast-forward update
origin	Name of your remote repository (GitHub)
main	Remote branch from which changes are pulled


Copy your working files without copying the old .git directory:
rsync -av --exclude='/.git/' \
  ~/DEVOPS-Journey/ \
  ~/DEVOPS-Journey-Fresh/


Part	                Meaning

rsync	                Copies or synchronizes files and directories

-a	                Archive mode: preserves directory structure, permissions, timestamps, etc.

-v	                Verbose mode: displays information about what's being copied

--exclude='/.git/'	Excludes the top-level .git directory from copying

\	                Continues the same command on the next line

~/DEVOPS-Journey/	Source directory — where files are copied from
~/DEVOPS-Journey-Fresh/	Destination directory — where files are copied to



**Why did we choose rsync instead of cp or mv?
Linux provides several commands for working with files.
Command	               Purpose	                                 Main difference

cp	         Copy files and directories	                 Simple file copying

mv	         Move or rename files and directories	         Removes them from the original location when moving

rsync	         Copy and synchronize files	                 Supports exclusions, previews, and efficient repeated copying
