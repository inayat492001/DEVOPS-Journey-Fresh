
                      Part A — Linux Basics & Navigation

1.What is an operating system, and what role does Linux play?

A: An operating system (OS) is system software that manages computer hardware and software resources, and provides common services for computer programs.
   
   Linux is an Open Source  operating system (OS), similar to Windows, macOS, or iOS, that manages the communication between software and hardware on a computer or 
   device, enabling programs to run efficiently and reliably. The core of Linux is the kernel, which handles CPU, memory, and peripheral devices, forming the lowest    level of the OS.

2.What is a Linux distribution? Name any three from the course material.

A: 1.Ubuntu: A user-friendly distribution with long-term support and a large community. 

   2.Kali Linux: Designed for cybersecurity tasks like penetration testing and ethical hacking. 

   3.Debian: Known for its stability and often used as a base for other distributions. 

These distributions cater to different user needs, from beginners to advanced system administrators and developers. Each distribution has its own package management system and desktop environment, providing flexibility and customization based on user preferences.

12. Copy notes.txt into backup.

A: To copy notes.txt into the backup directory, use the cp command.
Step 1: Copy the file
If you're currently inside linux-assessment/files, run:
cp notes.txt ../backup/


Step 2: Verify the copied file
ls ../backup/


Expected output:
notes.txt


Step 3: Display the copied file
cat ../backup/notes.txt


Explanation
Command	Meaning
cp	Copy a file or directory
notes.txt	Source file
..	Parent directory (linux-assessment)
../backup/	Destination directory
Alternative: Copy from any location
cp ~/linux-assessment/files/notes.txt ~/linux-assessment/backup/


Linux assessment tip: The cp command copies a file without deleting the original.
After copying, your directory structure will be:
linux-assessment/
├── files/
│   ├── app.log
│   ├── users.txt
│   └── notes.txt
├── logs/
└── backup/
    └── notes.txt


✅ Remember: cp copies files, whereas mv moves or renames them.

14. Create an empty directory named temporary, then remove it.

A: To create an empty directory named temporary and then remove it, use the mkdir and rmdir commands.
Step 1: Navigate to linux-assessment
cd ~/linux-assessment


Step 2: Create the directory
mkdir temporary


Step 3: Verify the directory was created
ls


Expected output:
backup  files  logs  temporary


Step 4: Remove the empty directory
rmdir temporary


Step 5: Verify the directory was removed
ls


Expected output:
backup  files  logs


Important: rmdir vs rm -r
Command	Purpose
mkdir temporary	Creates a directory
rmdir temporary	Removes an empty directory
rm -r temporary	Removes a directory and its contents
Linux assessment tip: Use rmdir when the directory is empty. It's safer than rm -r because it won't accidentally delete files inside the directory.
✅ Assessment answer (two commands):

18. Search notes.txt for a word in your sample text.

A: To search for a word inside notes.txt, use the Linux grep command.
Step 1: Search for a word
If you're currently inside linux-assessment, run:
grep "Linux" files/notes.txt


Step 2: Expected Output
I am learning Linux commands.
Linux is important for DevOps.


The grep command displays all lines containing the word Linux.
Step 3: Understand the command
Command	Meaning
grep	Searches for matching text inside files
"Linux"	Word you want to search
files/notes.txt	File to search
Other useful grep commands
# Case-insensitive search
grep -i "linux" files/notes.txt

# Show matching line numbers
grep -n "Linux" files/notes.txt

# Count matching lines
grep -c "Linux" files/notes.txt


Linux assessment tip: grep is widely used in DevOps for searching log files, identifying errors, and troubleshooting applications.

19. Find every file named notes.txt under linux-assessment.

A: To find every file named notes.txt under linux-assessment, use the Linux find command.
Step 1: Run the command
If you're currently inside linux-assessment:
find . -type f -name "notes.txt"


Step 2: Expected Output
./files/notes.txt
./backup/notes.txt


Step 3: Understand the command
Command	Meaning
find	Searches for files and directories
.	Start searching from the current directory
-type f	Search only for files
-name "notes.txt"	Find files with the exact name notes.txt
Alternative: Search from any directory
find ~/linux-assessment -type f -name "notes.txt"


This searches the linux-assessment directory and all its subdirectories.
Linux assessment tip:

- -type f → Find files only.
- -type d → Find directories only.
- -iname → Search without case sensitivity.

20. Count lines, words, and characters in notes.txt.

A: To count the lines, words, and characters in notes.txt, use the Linux wc (Word Count) command.
Step 1: Run the command
If you're currently inside linux-assessment:
wc -l -w -m files/notes.txt


Step 2: Understand the command
Option	Meaning
wc	Word Count command
-l	Counts lines
-w	Counts words
-m	Counts characters
files/notes.txt	File to analyze
Step 3: Example output
3  16  94  files/notes.txt


The numbers represent:
- 3 — Number of lines
- 16 — Number of words
- 94 — Number of characters
These are example values. Your actual results depend on the contents of your file, including newline characters.
Alternative: From any directory
wc -l -w -m ~/linux-assessment/files/notes.txt


Important Linux assessment tip
- wc -l → Count lines
- wc -w → Count words
- wc -m → Count characters
- wc -c → Count bytes
Remember: -m counts characters, while -c counts bytes. They can differ when a file contains Unicode characters.
