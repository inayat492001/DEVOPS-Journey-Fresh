Links:

Hard Link:
A Hard Link is an exact copy/mirror of the original filename that  points directly to the "Inode" on the link.

Syntax: ln original.txt hardlink.txt

Soft Link:(Symbolic Links)
A soft link is a "special independent file" that points to the text path of "another file name" rather that pointing to inode.

It has it own unique inode number.

Syntax: ln -s 

ex: ln -s org.txt softlink.txt

=>Constraints:

-->Hard links:
>Cannot spam/use accross the file systems
>Cannot link to the directories
>No independent permission

--> Soft Link:
>Vulnerable and get broken easily
> requires a storage overhead (require own inode and a small amount of disk space)
