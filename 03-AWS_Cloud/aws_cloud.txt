==> Cloud Computing:


  Cloud computing is the delivery of computing services such as servers, storages, databases, networking, software, analytics. "Over the internet" with pay as you go pricing.


-- Very low upfront cost.
-- Faster innovation
-- Better Disaster Recovery
-- Global reach


--> Limitations of cloud computing:
 
 - Requires reliable internet connectivity
 
 - Cost can increases if resurces are not managed properly
 


                        Traditional                                           Cloud
                        -----------                                           -----

-- Hardware           Company buy services                                AWS owns the hardware

-- Setup time         Weeks or months                                     Within Minutes

-- Cost Model         Large upfront cost                                  Pay-as-you-go

-- Scaling             Manual and Slow                                     Automatic and on-demand

-- Maintenance        Company handles repairs & Upgrades                  Aws handles physicaal Infrastructure

==> Types of Cloud Services:

1) Iaas (Infrastructure as a Service)

--> Aws gives you basic Infrastructure 
   : Virtual Machines,Storage, Network

You manages: OS, runtime, Security Configs

Aws Manages: Physical Services, Networking hardware storage hardwares

2) PaaS (Platform as a Services)

--> Aws gives you a platform to run applications without managing servers.

You Manages -> Application code, configs data

Aws Manages -> Run time, servers, scaling infra.


3) SaaS (Software as a Services):

--> Aws or another provider gives you a complete application 

--> You Manage: User settings Data managment 
--> Aws Manager: Application, Servers, Infra

Ex: Gmail, MS 365, Zoom and etc..


=> Types of models in cloud:

1) Public Cloud:
 -> Resources are managed and owned by cloud provider and share among many customers.

   Ex: Aws public cloud
      
2) Private Cloud:

-> Cloud Infrastructure used exclusively by organization it may be hosted on premises/ provided facility.

Ex: Bank running a private cloud in its own data center.


3) Hybrid Cloud:

-> Combination of both publc and private infrastructure connected together.

Ex: An application runs on -premises, but during festival time it bursts into AWS for extra capacity.

4) Multi Cloud:

-> Using more than one "public cloud provider"

Ex: Application runs partly on Aws, partly on Azure

      HTTP                       80
 
Listner = port + protocol + Action-->(Usually sends traffic to a target group)

=> Aws S3 (Simple Storage Services)

-> Amazon S3 is a "Object Storage" for files, Images, Logs, Backups and application data.

Before S3:

  -> Hard disks    |     Limited Accessibility
  -> File Servers  |     Hardware Failures
  -> Backup tapes  |     Difficult to Scale



=> Core concepts of S3:

1) Bucket:
 
 -> A bucket is a top-level container in S3.

 -> Bucket name is global, but it conents are regional.


2) Object:

  -> An objecct is a file stored in S3.
It contains:

       1.Object Data
       2.Meta Data
       3.Version ID
       4.Key(Reference path 27:30)

3) Key:
 
 -> The key is the full name/path of object inside the bucket.

Ex:- images/banner.png

4) Storage Classes:

 S3          Standard                  Frequently Accessed Data


 S3         Intelligent-Tiering        Reads Access Pattern
 

 S3         Standard- IA               Infrequently accessed data, rapid retrival


 S3         Glacier                    Long term Archives, Lowest Cost, Slowest retrival



5) Versioning:

-> Versioning Keys multiple versions of the same object.

Ex:- practice.txt V1
   
     practice.txt V2

-> It helps in : accidental deletions
    
               : Recover Old Files

               : Track changes

6) Lifecycle Rules:

-> Life cycle rules automate object movement or deletion.

       
                   Standard S3
                       |    After 30 days move to 
                   Standard IA
                       |    After 90 days move to   
                   S3 Glacier 
                       |    After 365 days
                   Delete It
